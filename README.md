# Pet Shop PUC

Projeto desenvolvido para a **Fase 1 da disciplina de Web Development**, com o objetivo de aplicar os conceitos iniciais de desenvolvimento web por meio da construção de um sistema para um petshop utilizando HTML.

Nesta primeira etapa, o projeto é desenvolvido sem a utilização de CSS, Bootstrap ou JavaScript, concentrando-se na estrutura e organização semântica das páginas HTML.

## Objetivo

Desenvolver um sistema web básico para o **Pet Shop PUC**, permitindo que os usuários conheçam o estabelecimento e visualizem informações sobre seus produtos e serviços.

O projeto também busca aplicar na prática os conceitos fundamentais de HTML estudados durante as primeiras aulas da disciplina, incluindo estruturação de páginas, navegação, organização semântica de conteúdo, utilização de imagens, formulários e links.

## Metas

Para atingir o objetivo proposto, foram definidas as seguintes metas:

* Criar uma estrutura de navegação entre as diferentes páginas do sistema.
* Desenvolver uma página inicial contendo informações gerais sobre o Pet Shop PUC e sua localização.
* Disponibilizar três categorias de produtos: **Alimentação, Brinquedos e Higiene**.
* Apresentar dois produtos de cada categoria, contendo nome, imagem, descrição e valor.
* Criar uma página para apresentação dos serviços oferecidos pelo petshop.
* Informar a descrição, o preço e a disponibilidade de tele-busca para cada serviço.
* Criar uma página de contato contendo um formulário para envio de mensagens.
* Utilizar elementos semânticos do HTML, como `nav`, `section`, `article` e `footer`, para organizar o conteúdo das páginas.
* Disponibilizar informações de autoria e identificação do projeto no rodapé das páginas.
* Publicar o código-fonte do projeto em um repositório no GitHub.
* Disponibilizar o sistema na web utilizando o GitHub Pages.

## Estrutura do sistema

O sistema é composto pelas seguintes páginas:

* **Início (`index.html`)**: apresenta o Pet Shop PUC, informações gerais e sua localização.
* **Produtos (`produtos.html`)**: apresenta os produtos disponíveis, organizados nas categorias Alimentação, Brinquedos e Higiene.
* **Serviços (`servicos.html`)**: apresenta os serviços oferecidos, seus respectivos valores e a disponibilidade de tele-busca.
* **Contato (`contato.html`)**: disponibiliza um formulário para que o usuário possa enviar uma mensagem ao petshop.
